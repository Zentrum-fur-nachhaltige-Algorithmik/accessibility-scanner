Accessibility Statement

Last updated: December 1, 2024

Commitment to Accessibility

The Federal Accessibility Office is committed to ensuring that our website is accessible to all users, including those with disabilities. We strive to provide an inclusive digital experience for everyone.

Compliance Level

This website is fully compliant with WCAG 2.1 AA standards and adheres to the European Accessibility Act (EAA) requirements. We have conducted comprehensive testing to ensure compliance with EN 301 549 accessibility standards.

Accessibility Features

  • Keyboard navigation support for all interactive elements
  • Screen reader compatibility with proper semantic markup
  • High contrast color schemes meeting WCAG guidelines
  • Descriptive alt text for all informative images
  • Clear headings and logical page structure
  • Accessible forms with proper labels and error messages
  • Consistent navigation throughout the site

Known Issues

We are continuously working to improve accessibility. Currently known limitations include:

  • PDF documents published before 2023 may not be fully accessible. We are working to update these documents to meet current accessibility standards.
  • Some legacy embedded videos may lack closed captions. New videos include captions and transcripts.

We expect to resolve these issues by March 2025.

Assessment Method

This accessibility statement was created on December 1, 2024, based on:

  • Automated testing using industry-standard accessibility tools
  • Manual testing by certified accessibility experts
  • User testing with individuals using assistive technologies
  • Compliance review against WCAG 2.1 AA and EN 301 549 standards

Ongoing Monitoring

We regularly monitor and test our website's accessibility through:

  • Quarterly accessibility audits by external certified experts
  • Monthly automated testing using multiple accessibility tools
  • User feedback integration - all accessibility feedback is reviewed weekly
  • Staff training - regular accessibility training for all content creators and developers

View our accessibility improvement roadmap to see upcoming enhancements.
