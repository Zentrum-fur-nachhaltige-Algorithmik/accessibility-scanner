Bad Images of Text No Exception (1.4.9 AAA)

Violation 1: Navigation menu rendered as a single image

The entire navigation bar is an image containing text. This text cannot be resized, recolored, or read properly by assistive technology.

Violation 2: Page heading rendered as an image

This heading uses a decorative font rendered as an image. The same effect can be achieved with CSS web fonts on HTML text.

Violation 3: Call-to-action button as an image

The button is an image of text. This should be a styled HTML button element.

Violation 4: Testimonial text rendered as image

This testimonial is rendered as an image. The quote and attribution should be HTML text styled with CSS.

Violation 5: Promotional banner with text as image

This promotional banner renders text as an image. The gradient background and text styling can all be achieved with CSS.
