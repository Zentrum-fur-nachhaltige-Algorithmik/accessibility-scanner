Understanding ARIA Landmarks

ARIA landmarks provide a way to identify regions of a page in a programmatic way. This helps assistive technology users navigate and understand page structure.

Proper landmark usage includes:

  • One banner landmark per page
  • One main landmark per page
  • One contentinfo landmark per page
  • Multiple navigation landmarks with distinguishing labels
  • Complementary landmarks at top level only

Perfect landmark structure achieved

Landmark compliance features:

  • ✅ Single banner landmark (header element at top level)
  • ✅ Single main landmark (main element)
  • ✅ Single contentinfo landmark (footer element at top level)
  • ✅ Multiple navigation landmarks with distinguishing aria-label attributes
  • ✅ Multiple search landmarks with distinguishing aria-label attributes
  • ✅ Complementary landmarks (aside elements) only at top level
  • ✅ Region landmarks with proper aria-labelledby references
  • ✅ No improper nesting of landmark elements
  • ✅ Form elements used correctly instead of role="form" on divs
  • ✅ Article landmarks containing appropriate content

Screen reader users can efficiently navigate by landmarks without confusion or structural conflicts.
