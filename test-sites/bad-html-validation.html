    VIOLATION 6: Gebrochene Heading-Hierarchie

    Problem: Falsche Heading-Reihenfolge bricht Screenreader-Navigation

    Kaputte Heading-Struktur

    Haupttitel (H1)

    Übersprungene Ebene - sollte H2 sein!

    Noch weiter übersprungen - sollte H3/H4/H5 sein!

    Zurück zu H2 nach H6 - verwirrend!

    Erster H1

    Zweiter H1 - sollte H2 sein!

    Heading-Probleme: - H1 → H4 (übersprungene H2, H3 Ebenen) - H4 → H6 (übersprungene H5 Ebene) - Mehrere H1 auf einer Seite - Leere Headings ohne Inhalt
    VIOLATION 7: Ungültige ARIA-Role/Attribut-Kombinationen

    Problem: Falsche ARIA-Kombinationen verwirren Screenreader

    Ungültige ARIA-Kombinationen

    Button ohne Keyboard-Zugang
    Kein checkbox/radio aber aria-checked
    Kein option/tab aber aria-selected Kein expandierbares Element
    ARIA-Probleme: - role="button" ohne tabindex (nicht keyboard-zugänglich) - aria-checked ohne checkbox/radio role - aria-selected ohne option/tab role - aria-expanded ohne expandierbare role - Falsche roles für native Elemente
    VIOLATION 8: Fehlende Required-Attribute für ARIA-Roles

    Problem: ARIA-Roles ohne notwendige begleitende Attribute

    Unvollständige ARIA-Implementierungen

    Slider ohne Wert-Attribute
    Progress ohne Wert
    Textbox ohne multiline info
    Combobox ohne expanded state
    Tab ohne Orientation
    Fehlende ARIA-Attribute: - slider: aria-valuemin, aria-valuemax, aria-valuenow - progressbar: aria-valuenow - textbox: aria-multiline - combobox: aria-expanded - tablist: aria-orientation
