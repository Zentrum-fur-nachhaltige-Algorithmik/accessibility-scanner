Compliant (3.1.3): Technical jargon defined on first use and in glossary

The system uses a microservices architecture (a design pattern where an application is composed of small, independent services). Each bounded context (a self-contained subsystem with its own data model) communicates via an event bus using the saga pattern (a sequence of local transactions that maintain data consistency across services).

Glossary

Microservices architecture
A design pattern where an application is composed of small, independently deployable services.
Bounded context
A self-contained subsystem within a larger application, with its own data model and logic.
Saga pattern
A sequence of local transactions where each step triggers the next, maintaining consistency across distributed services.
