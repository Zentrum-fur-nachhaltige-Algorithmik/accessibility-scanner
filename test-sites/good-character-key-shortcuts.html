Proper Keyboard Shortcuts (GOOD)

This page demonstrates WCAG 2.1.4 compliance: shortcuts use modifier keys and/or can be disabled and remapped.

Pattern 1: Shortcuts with Modifier Keys

All shortcuts require a modifier key (Ctrl or Ctrl+Shift), preventing accidental activation by speech input or screen reader users.

Pattern 2: Disableable and Remappable Shortcuts

Navigate the feed using keyboard shortcuts. You can disable or remap all shortcuts in settings.
