Accessibility Statement

This accessibility statement applies to our website. We want everybody to be able to use it. We are working on removing the barriers we know about. This statement deliberately omits the conformance level, the accessibility contact point and the last review date, so that scanners which check the completeness of an existing statement have something to find. It is long enough to pass the length threshold that separates a real statement from an incidental mention of the word accessibility somewhere on a page.
