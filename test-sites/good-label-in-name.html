GOOD 9: Best Practices für Label in Name

WCAG 2.5.3 Compliance Regeln:

  1. Sichtbarer Text zuerst: aria-label sollte mit dem sichtbaren Text beginnen
  2. Native Labels bevorzugen: <label for=""> ist besser als aria-label
  3. Konsistenz: Alle Namensquellen sollten übereinstimmen
  4. Voice-Control freundlich: Benutzer sollen sagen können, was sie sehen
  5. Erweitern, nicht ersetzen: aria-label kann sichtbaren Text erweitern
