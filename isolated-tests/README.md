# Isolated Tests for Debugging

This folder contains isolated test cases organized by their classification to speed up debugging of scanner issues.

## Folder Structure

### false-positives/
Contains HTML files and scanner combinations where scanners incorrectly flag content as having violations when they shouldn't.

**Example**: `color-contrast-scanner` detecting violations in `good-accessibility.html`

### false-negatives/
Contains HTML files and scanner combinations where scanners miss actual accessibility violations they should detect.

**Example**: `page-structure-scanner` not detecting missing alt text in `bad-image-alt.html`

### true-positives/
Contains correctly working scanner combinations that detect expected violations.

**For validation**: These should continue working as expected.

### true-negatives/
Contains correctly working scanner combinations that properly ignore content without relevant violations.

**For validation**: These should continue working as expected.

## File Naming Convention

Files are named: `{scanner-name}_{test-file-name}_{classification}.html`

Example: `color-contrast_bad-focus-visible_FALSE_NEGATIVE.html`

## Usage

1. **Focus debugging** on false-positives and false-negatives folders
2. **Validate fixes** don't break true-positives and true-negatives
3. **Run targeted tests** on specific classifications
