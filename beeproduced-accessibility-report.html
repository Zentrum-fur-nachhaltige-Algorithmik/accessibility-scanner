🚨 Gefundene Accessibility-Probleme

Es wurden 3 Accessibility-Probleme identifiziert, die behoben werden sollten:

CRITICAL
Logo-Link ohne Alt-Text
Das Hauptlogo im Header ist ein Link, aber das Bild hat keinen Alt-Text. Screen Reader-Nutzer können nicht verstehen, wohin dieser Link führt.
<a aria-current="page" href="/" class="router-link-active router-link-exact-active" aria-label="Home"> <img onerror="this.setAttribute..." /> </a>
WCAG 2.1 Kriterium 1.1.1 - Non-text Content

Alle Nicht-Text-Inhalte müssen eine Textalternative haben, die den gleichen Zweck erfüllt.

💡 Lösungsvorschlag:

Fügen Sie dem Logo-Bild einen aussagekräftigen Alt-Text hinzu:

<img src="logo.png" alt="bee produced - Zur Startseite" />

Geschätzter Aufwand: 5 Minuten

CRITICAL
E-Mail-Eingabefeld ohne Label
Das E-Mail-Eingabefeld im Footer hat nur einen Placeholder, aber kein zugängliches Label. Screen Reader können das Feld nicht richtig identifizieren.
<input value="" type="email" placeholder="E-mail" required="" data-v-9ac491c1="">
WCAG 2.1 Kriterium 4.1.2 - Name, Role, Value

Für alle Benutzeroberflächen-Komponenten müssen Name und Rolle programmatisch bestimmt werden können.

💡 Lösungsvorschlag:

Fügen Sie ein unsichtbares Label oder aria-label hinzu:

<input type="email" placeholder="E-mail" aria-label="E-Mail-Adresse für Newsletter" required />

Geschätzter Aufwand: 10 Minuten

MODERATE
Iframe ohne Titel
Es gibt ein verstecktes Iframe ohne title-Attribut. Auch wenn es versteckt ist, sollte es einen beschreibenden Titel haben.
<iframe height="0" width="0" style="display: none; visibility: hidden;"></iframe>
WCAG 2.1 Kriterium 2.4.1 - Bypass Blocks

Iframes müssen einen nicht-leeren title haben, der den Frame identifiziert.

💡 Lösungsvorschlag:

Fügen Sie einen beschreibenden Titel hinzu oder verwenden Sie aria-hidden:

<iframe title="Tracking Pixel" height="0" width="0" style="display: none; visibility: hidden;" aria-hidden="true"></iframe>

Geschätzter Aufwand: 5 Minuten

MODERATE
Cookie-Banner außerhalb von Landmarks
Der Cookie-Banner-Inhalt befindet sich nicht innerhalb eines semantischen Landmarks. Dies kann die Navigation für Screen Reader-Nutzer erschweren.
Best Practice - Semantic Structure

Alle Seiteninhalte sollten in semantischen Landmarks organisiert sein.

💡 Lösungsvorschlag:

Wickeln Sie den Cookie-Banner in ein semantisches Element:

<aside role="banner" aria-label="Cookie-Einstellungen">...</aside>

Geschätzter Aufwand: 15 Minuten
