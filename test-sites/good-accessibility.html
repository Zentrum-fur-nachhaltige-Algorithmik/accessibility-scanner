✓ Zusammenfassung der guten Praktiken

  • Farbkontraste: Alle Texte haben mindestens 4.5:1 Kontrast (7.0:1+ für großen Text)
  • Links: Unterstrichen UND farblich unterschieden
  • Formular-Fehler: Rot + Text + Icon + Rahmen
  • Pflichtfelder: Text "(erforderlich)" statt nur Sterne
  • Status-Nachrichten: Icon + Text + Hintergrundfarbe + Rahmen
  • Navigation: Aktiver Zustand durch Text + Farbe + Rahmen
  • Diagramme: Legende mit Text und Farbbeschreibung
  • Verfügbarkeit: Symbol + Text + Hintergrundfarbe
  • Tabellen: Textuelle Sortierbeschreibung
  • Kalender: Icons + Text + Farbcodes mit Legende
