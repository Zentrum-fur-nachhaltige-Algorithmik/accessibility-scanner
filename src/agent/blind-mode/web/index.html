Keys

  • Arrow down / Arrow up: one element forward or back
  • Tab / Shift+Tab: next interactive element
  • H / Shift+H: next heading
  • L / Shift+L: next link
  • F / Shift+F: next form field
  • D / Shift+D: next landmark
  • Enter: activate, in a text field: input mode
  • Esc: cancel, close dialog
  • R: repeat the last announcement
  • ?: read this key list aloud
  • Esc Esc: leave the game

Every key press is one step. At the end your route is compared with the shortest possible one.

? reads the keys aloud, R repeats the last announcement. Neither costs a step.
