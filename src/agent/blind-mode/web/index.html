Modus

Schwarzer Bildschirm. Du hörst nur, du liest nichts.

Die letzte Ansage steht zusätzlich als Text da.

Wir speichern nur Tastenfolge und Ansagen, keine Person.

Deine Aufgabe

Tasten

  • Pfeil runter / Pfeil hoch: ein Element weiter oder zurück
  • Tab / Shift+Tab: nächstes bedienbares Element
  • H / Shift+H: nächste Überschrift
  • L / Shift+L: nächster Link
  • F / Shift+F: nächstes Formularfeld
  • D / Shift+D: nächster Seitenbereich
  • Enter: auslösen, in einem Textfeld: Eingabemodus
  • Esc: abbrechen, Dialog schließen
  • R: letzte Ansage wiederholen
  • ?: diese Tastenliste vorlesen
  • Esc Esc: Spiel verlassen

Jeder Tastendruck ist ein Schritt. Am Ende vergleichen wir mit dem kürzesten möglichen Weg.

? liest die Tasten vor, R wiederholt die letzte Ansage. Beides kostet keinen Schritt.
