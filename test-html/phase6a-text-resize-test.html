🧪 Scanner Testing Guidelines

Expected Scanner Behavior:

  • Text Resize Scanner (1.4.4) should detect:
    • ❌ Fixed width elements that cause horizontal scrolling at 200% zoom
    • ❌ Fixed font sizes that don't scale properly
    • ❌ Overflow hidden on containers with fixed dimensions
    • ❌ Tables requiring horizontal scrolling at zoom
    • ❌ Navigation elements that become unusable at zoom
    • ✅ Responsive layouts using relative units (em, rem, %)
    • ✅ Flexible containers that reflow at zoom
    • ✅ Forms that remain usable at 200% zoom
  • Text Spacing Scanner (1.4.12) should detect:
    • ❌ Line height less than 1.5x font size
    • ❌ Paragraph spacing less than 2x font size
    • ❌ Letter spacing that cannot be adjusted to 0.12x font size
    • ❌ Word spacing that cannot be adjusted to 0.16x font size

Testing Procedure:

  1. Load this page in browser at 100% zoom in 1280px wide viewport
  2. Run baseline accessibility scan
  3. Set browser zoom to 200%
  4. Re-run scan and compare results
  5. Check for horizontal scrolling in viewport
  6. Verify all interactive elements remain accessible
  7. Test text spacing overrides with CSS user stylesheet

Success Criteria:

PASS: All content and functionality available at 200% zoom without horizontal scrolling

FAIL: Content lost, functionality impaired, or horizontal scrolling required at 200% zoom
